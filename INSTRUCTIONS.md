# Quick Command

## Quick Command is a popup command bar that allows you to run powershell, bash, zsh, command prompt, etc (whatever your system supports) as well as custom commands that can be defined either manually or with the help of AI (which will define the command for you if you tell it what it should do).


## Who it's for
The average computer nerd and shortcuts wiz. I love my shortcuts so being able to pull up a window and type in a command to open a specific application would be really cool.

## The 3 things it MUST do
1. Run a terminal.
2. Be a miniature-sized command bar (UI).
3. Support custom-defined commands.

## Nice-to-haves (only if there's time)
- Have an AI that will help the user define or code in custom commands.
- Support multiple shells, such as bash, zsh, command prompt, unix, powershell, depending on the system.

## The vibe
Should be a desktop application that works across Windows and Mac (can be separate versions/releases for windows and mac but same functionality). Should have settings menu that can define     whether the light scheme is system default, light, or dark. The UI should be minimalistic, with a small, rounded bar near the bottom of the screen; its shape looks like the Mac spotlight search. It should load very fast at the press of a button or the press of a keyboard command (CTRL+something), with only space for text for the command, a menu button to switch shells, get to settings, see history, etc. After the command is run, the bar should only stay on the screen and show previous commands typed if necessary (i.e. additional prompts, etc. - this will probably be most of the time and the bar will only get off the screen if there's a command to open an application, for example).

## What "done" means / Minimum Viable Product
A proper UI for a spotlight search-like bar with at least one shell, a way to define commands, and a working interface.
